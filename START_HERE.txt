HEAVYFEEL / HEAVYPRO - START HERE
=================================

1. Double-click Setup-SimConnect.bat (next to HeavyFeel.sln)
   - Or run: scripts\Setup-SimConnect.ps1
   - If Windows hides extensions it may appear only as "Setup-SimConnect"

2. Double-click HeavyFeel.sln so it opens in Visual Studio 2022

3. In Solution Explorer: right-click HeavyFeel.App → Set as Startup Project

4. Press F5 (or the green Play button)

5. Start MSFS 2024, load an aircraft (Fenix A320 recommended), click Connect if needed

See README.md and HOW_TO_RUN.txt for full details, troubleshooting, and what "good" looks like.

Master Enable writes AXIS events only while you hold the stick.
Body-rate writes are intentionally disabled.
