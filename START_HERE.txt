HEAVYFEEL - START HERE
======================

The PowerShell script is here:

  scripts\Setup-SimConnect.ps1

If you do not want to use that, double-click this file instead:

  Setup-SimConnect.bat

That .bat file sits next to HeavyFeel.sln so it is easy to see.

Then:

  1. Open HeavyFeel.sln in Visual Studio 2022
  2. Press F5

If Windows hides file extensions, Setup-SimConnect.bat may just look like
"Setup-SimConnect".
