This package holds the HeavyPro profile. The Windows app reads HeavyPro/profiles.json from the installed Community folder via %LOCALAPPDATA%\HeavyPro\community.path.

Toolbar: incomplete. HeavyPro.spb is not included. MSFS 2024 only shows a toolbar icon if that compiled SPB exists. The MSFS 2024 SDK Project Editor is required to compile it. HTML alone does not create the icon.

This package does not change aircraft mass, moment of inertia, or the flight model.
